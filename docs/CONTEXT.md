## Architecture

Vite 6 + React 19 + TypeScript, strict and `noUncheckedIndexedAccess`. The poster is the only app: `src/main.tsx` mounts `PosterApp`. v1 polity tables stay in `src/data/legacy.ts` and the files it reads, because the catalog re-export and the lineage scripts still use them. v2 schemas live in `src/data/schema` (zod is the source of truth). `src/data/index.ts` loads the v2 catalog and re-exports the v1 barrel from `legacy.ts`. `src/layout` has serializable types, `projectX`, time slices, the lane solver, drift limiting, split/merge seeding, multi-zone ribbons, ribbon paths, uncertainty caps, flow-conserving connectors, connector strokes, label fitting, short-ribbon labels, callout placement, level of detail, the memoized orchestrator in `src/layout/index.ts`, the layout metrics, a debug payload of lanes, boxes, and violations, and golden fixtures A–H. `npm run layout:report` writes `docs/reports/layout-latest.json`. `src/styles/tokens.css` holds the parchment and night-atlas tokens. `src/ui` is the poster shell: title band, frame, era gutters, and a slim top bar. The theme choice is stored in localStorage. A reading key lists lineage colors and is closed until asked. `?v1=1` no longer switches apps. `src/camera` is the pan, zoom, clamp, fit, and fly math. `src/render` is the stage: an SVG viewBox in design px, era bands and year ticks in both gutters, gridlines, a Natural Earth watermark, relation connectors, cross-cutting bands, ribbons with labels, y-window culling, zoom controls, and an overview minimap. `src/data/clientDataset.ts` loads the same JSON the validator reads. `src/state` holds lineage focus and the shareable view. The address hash stores `y`, `z`, `sel`, `lens`, `fold`, and `pin`. The lens control, search, and the columns panel write it, and back and forward read it. Fold hides a family or macro-region. Pin keeps only the chosen columns. The layout solves again, and the ribbons move for 300 ms unless reduced motion is on. Search scrolls the chart to `y` and marks `sel`. A ribbon click opens the dossier; it stays closed until then. A polity with a Wikipedia title can load a short extract after a click, labeled From Wikipedia. A horizontal crosshair follows the pointer over the chart. Locking it opens a snapshot of importance 3 states by macro-region. The snapshot stays closed until then. Play steps that year forward; reduced motion disables it. A lens dims the rest of the chart and reveals the arcs it is about. Hover thickens the active arc. The chart never drops to zero opacity. The columns panel applies the five migrated presets and stores named compares in localStorage. Stories plays the three migrated tours: a stop sets the year, the camera scale in `z`, a chart lens, and the highlighted polity. Fit width clears `z`. Table view lists the same polities and the callouts attached to them, sorted and filtered, and paints only the rows in view. Ribbon tab order runs down the poster, then left to right. Skip controls jump to the chart and to search. A panel takes focus when it opens and returns it when it closes. Reduced motion drops transition time to zero. Scrolling does not push a history entry. ## Commands

`npm run check` = typecheck + lint + design:lint + palette:check + vitest (layout coverage ≥ 85%) + validate:data. `npm run shots` writes the poster scenes to `docs/shots/p3/`. The v1 baselines stay in `docs/shots/v1/`. `npm run dev` / `build` / `preview`. `validate:data` loads relations and roots. An orphan warning means a polity is neither a target nor a reasoned root. `npm run perf` pans and zooms a 300-ribbon bench and fails when frame p95 exceeds 20 ms. Media and export commands are still stubs. `npm run layout:report` runs the real roster. `media:fetch` refuses to download while `ALLOW_MEDIA_DOWNLOAD=false`. Checklist rows are applied with `npx tsx scripts/apply-roster.ts <family>`. Relations are regenerated with `npx tsx scripts/write-lineage.ts`.
