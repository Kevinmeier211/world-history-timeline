# Reading and notebook follow-up

Kevin asked whether more could be done after the completed local release. A bounded review found concrete usability defects beyond the original acceptance checks. This pass repairs those defects; it is Codex self-review, with no separate agent or human tester.

## Result

- **Search and reading focus:** focus is assigned after React commits and the native search dialog finishes closing. A selected subject receives visible heading focus instead of leaving the keyboard on the page body. Dossier text and fonts finish loading before an evidence landing is positioned.
- **Evidence and world context:** Sources moves directly to “How do we know?” and its actual claim notes. Copied evidence links, reload, Back/Forward and folding notes preserve a visible reading target. Show in world context brings the map context into view, including when that presentation was already selected. Object selection and journey transitions receive appropriate reading targets. Wide panes with their own scroll containers are included.
- **Clean notebook drafts:** a new save form resets the previous answer and collection. Cancelling a draft also prevents that abandoned answer from appearing under a later subject.
- **Storage failure:** a question remains in the current notebook session when browser persistence fails. The warning asks the reader to export, and the actual export contains those session entries. Successful persistence retains its normal message.

## Verification

`npm run test:reading` executes scripts/redesign/reading-checks.mjs against the 4174 preview. It checks search from a deeply scrolled overview, visible focused destinations, Sources, copied links, history, folding, repeated world-context activation, native save forms and real notebook downloads. Widths are 390, 768, 1440 and 1720 CSS pixels. The final width exercises nested desktop reading panes. Each evidence view has zero axe findings at every impact level.

Both normal storage and deliberately blocked notebook storage pass. Exports contain two distinct entries with the correct answers; a cancelled answer is absent. The script saves the structured receipt and a real phone evidence screenshot in output/redesign/followup/.

The full repository gate and original atlas browser suite pass again, including all ten journeys. Performance and package receipts are refreshed with the release. The historical corpus and three PDFs retain their prior checksums; these changes affect interactive reading and saving, not historical claim review.
